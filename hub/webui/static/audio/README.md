# Optional audio assets

The original third-party recordings are omitted from the public source release
because their distribution licenses were not recorded. The corresponding UI
cues are silent when the files are absent; the client handles playback failure.

To use recordings you have permission to distribute, supply these filenames:

- `ui-click.wav`: button click cue
- `report-submit.mp3`: report submission cue
- `map-ban.mp3`: confirmed map ban cue
- `map-ban-turn.mp3`: captain's turn cue

Keep their licenses with your distribution. These recordings are not covered by
Lights Out's MIT license. The original asset paths are retained for compatibility.
