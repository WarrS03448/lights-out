How it works

What it actually touches

Nothing here goes near the running game. The mechanism is the answer, so none of this has to be taken on trust.

How it works

Lights Out never ships you a piece of Bodycam. It ships a small pack of its own content, builds the mod on your PC from the copy of the game you already own, and drops one file where the game already looks for mods.

4 steps

  1. Install the app

    A small Windows program, installed to a folder it shows you first. For ranked play, sign in with Steam or create a Lights Out account.

  2. Pick a mode and hit install

    The app downloads a pack: a few tens of kilobytes of the gamemode’s own content. No game assets, because none are ours to send.

  3. The mod is built on your PC

    Everything the mode needs from Bodycam is read out of your own installed game files and combined with the pack locally. That is why it takes a minute, and why nothing of Reissad Studio’s is ever redistributed.

  4. One file lands in ~mods

    One file, CommunityGamemodes_P.pak, in Bodycam’s own ~mods folder, where the game already looks for mods. Uninstall deletes it and leaves the game as it found it.

What it never does

  • It never reads or writes the game’s memory and injects nothing into the running process. The app stays connected during ranked matches; the pak supplies the gamemode.
  • It never edits your game files. Everything it installs is additive: one extra file in ~mods.
  • It gives no advantage in Bodycam’s own modes. It adds new modes; it doesn’t change existing ones.
  • It never receives your Steam password. Choose Steam sign-in or a Lights Out email/password account. Bodycam still runs through Steam; the app verifies your game identity to match you to the right player. See what data Lights Out collects.
