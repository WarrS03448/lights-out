FAQ

Is it free?

Yes, completely. No account, no sign-up, no ads, no premium tier.

How do I play ranked?

Install Bodybomb 5v5 in the app, sign in with Steam on the Competitive tab, and hit Find match. Ranked needs the current version of both the app and the mode; the app updates itself. Inside a ranked match walks through the rest.

What gameplay and app information is recorded?

Lights Out records match formation, results, available round and combat statistics, rating decisions, app actions, connection outcomes, and diagnostic error codes. Signed-in activity is associated with your Steam account so administrators can investigate failures, assess matchmaking, and make longer-term balance decisions.

The analytics console is restricted to administrators. New diagnostic capture excludes chat and report text, passwords, sign-in tokens, IP addresses, local file paths, screenshots, and raw exception messages. Existing features such as player reports and match chat keep their own records separately.

Detailed operational events are kept for 30 days, analytical match records for one year, and daily statistical totals for three years. Existing authoritative result and rating receipts keep their current lifetime. The app queues up to 1,000 diagnostic events within a 1 MiB local file and retries when connected; missing or partial gameplay evidence is marked as unavailable. Contact us with questions about your records.

How does ping detection work, and how is the host chosen?

While you search for a match, Lights Out connects to Cloudflare’s relay service and exchanges small test messages with other eligible players through that relay. It measures how long each message takes to travel to the other player and back, in milliseconds (ms). Lower readings mean less delay.

The app takes several readings in both directions and uses the middle reading to reduce the effect of brief spikes. Matchmaking uses the higher of the two players’ results for each connection, then compares possible hosts. It chooses the eligible player with the lowest average latency to everyone else, provided every connection to that host meets the ping limit. If averages tie, the host with the lower worst connection wins the tie.

These ping checks do not expose your public or local IP address to any other user of the app. Test messages travel through Cloudflare’s relay, so other app users connect to the relay instead of directly to your device. Cloudflare can see the IP address you connect from. This protection applies to Lights Out’s ping checks; Bodycam’s own game connections are separate. These are data-only tests; they do not need your camera or microphone.

This measures the app’s relay connection, not Bodycam’s actual in-game ping. The game uses its own network route, so your in-game reading may differ. These measurements help estimate the best host for the group; they do not guarantee a lag-free match. Missing or outdated results are treated as unavailable, not as zero ping.

Do my friends need it too?

Yes. A community gamemode has to be installed on every PC in the lobby, host and players alike. Everyone should install the same version; the app shows which one you have.

Windows says “Windows protected your PC”. Is the download safe?

Lights Out’s official Windows installer is digitally signed by Samuel Warren. Microsoft Defender SmartScreen also checks download reputation, so a signed installer can still trigger the “Windows protected your PC” warning while reputation builds. An unrecognized-app warning is not itself a malware detection, and a digital signature is not a guarantee that a file is safe.

If you downloaded the installer from this site and trust it:

  1. On the “Windows protected your PC” screen, click More info.
  2. Check that the publisher is Samuel Warren, then click Run anyway to start the Lights Out installer.
  3. Follow the installer’s on-screen instructions.

If Run anyway is missing, your device’s security settings or administrator may prevent this override. If Windows reports a specific threat, stop instead of following these steps. Contact us with the exact message for help.

Read Microsoft’s explanation of SmartScreen app reputation.

How do I remove it completely?

Uninstall inside the app takes the gamemode file back out of Bodycam. Lights Out itself then uninstalls like any Windows program; the only thing left behind is a few small settings files in %LOCALAPPDATA%\CommunityHub, which you can delete by hand.

Bodycam just updated. Do I need to do anything?

If a mode stops appearing after a game update, open the app and Install again, and it rebuilds the pak against your updated game files.

How do updates to the app or the gamemodes work?

Lights Out checks this site each time it starts. New gamemode versions show an “update available” note next to the mode, and a newer app version installs itself in the background, so there is no need to come back here.

Which languages does it support?

The same seven as Bodycam: English, German, Spanish, French, Portuguese, Russian and Chinese. It asks on first run and can be changed any time.
