# Lights Out 2.6.8

The Lights Out and tournament registration totals always appear side by side.
The header uses compact spacing in smaller windows so the totals and all
navigation buttons, including Tournament, stay on one row. Verified in all
seven supported languages down to the minimum window size.

Lights Out provides community game modes and matchmaking. Its purpose is not to
cheat, and the files it installs are not cheats. It is a community project, not
affiliated with or endorsed by Reissad Studio.
