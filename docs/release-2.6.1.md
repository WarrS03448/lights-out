# Lights Out 2.6.1

- Tournament scrolling stays in place during automatic refreshes. The Message a friend dropdown stays open while updates arrive.
- Tournament and message controls use the established square corners. The website tournament header includes Create account again.
- Banning a player during an active match automatically voids that match, with no rank gains or losses. A previously decided result remains unchanged.
- Tournament rules clearly require completing placements first. Placement matches count toward neither tournament RR nor the five eligible matches required for prizes.
- The cheating rules explain that recorded footage can be submitted through our Discord or Reddit page for quicker action.

The signed Windows client includes the tournament and messaging features from
[2.6.0](release-2.6.0.md). Bodybomb 5v5 remains 1.0.28 and Capture the Flag remains 1.0.4.
