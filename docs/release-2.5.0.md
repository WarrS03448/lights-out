# Lights Out 2.5.0

Match void voting now requires Yes votes from seven distinct authenticated match
participants. The new button reads “Cheater in the game? Click to vote to void
match. 7/10 Votes Required”. Duplicate votes and extra app windows do not count.
The threshold remains seven even when players leave.

Once the vote passes, the match is recorded as void with no rank or RR gains or
losses. Each connected app closes its match Bodycam process and shows MATCH
VOIDED in the result screen until dismissed. A disconnected app performs cleanup
when it reconnects. Voting and result text is available in all seven languages.

The official Windows installer is digitally signed by Samuel Warren.
Bodybomb 5v5 remains at 1.0.28 and Capture the Flag at 1.0.4.

[Download the Windows app](https://lightsoutranked.com/).
