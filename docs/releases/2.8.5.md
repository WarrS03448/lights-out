# Lights Out 2.8.5

Bodybomb 1v1 now includes Paintball, Airsoft and Bomb House. Each map has one
bombsite. Bomb House uses the downstairs site. The coinflip winner chooses
starting-side selection or the last map ban; each player bans one map.

All three maps count toward the launch tournament. Client and website titles
now say Bodybomb 1v1 without the Paintball suffix. Ranked rules remain first to
five, two-minute rounds, sides and spawns switching each round, and 3x drone
cooldown. Public bot play is not included.

A live host can no longer use Open game to launch a replacement world with a
spent travel permit. Hosts must use the server-authorized recovery path.
Participants retain reconnect, and hosts can retry before their first arrival.
The private solo bot test cannot restore a destroyed host world through the
normal two-human checkpoint path. Its reported black screen is not reproduced
or claimed fixed by a native test; this release prevents the unauthorized cold
host launch in the public client.

The client is based on 2.8.4, preserving native update-signature verification
and stock multiplayer enum compatibility. The BB1 authored pack is 1.0.4;
5v5 and CTF packs are unchanged. Single-site layers are built locally from the
player's installed game with pinned source fingerprints. Game-owned map bytes
are never included in downloaded packs.

Validation includes client/backend regressions, changed-snapshot veto controls,
tournament website layouts, local assembly with all three released gamemodes,
and signature and frozen self-check verification. Bomb House's retained actor
was checked as the downstairs site in the assembled layer. Additional native
gameplay testing was waived by the owner.

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
