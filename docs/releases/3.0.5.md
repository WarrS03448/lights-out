# Lights Out 3.0.5

This release updates the tournament rules text and fixes match recovery after
the host drops.

- Tournament net RR can no longer drop below 0. A loss while you are at 0
  RR costs nothing, and any total that was below 0 when the rule began on
  September 27 was raised to 0. Totals above 0 were not changed. The rules
  paragraph on the Tournament screen now says your score cannot drop below
  0 RR, in all seven languages.
- Recovering a match after the host drops now works. Reconnect no longer
  drops you into the shooting range when the host's game is gone: once the
  service reports that the host's game has stopped responding, the hub
  withdraws Reconnect and uses match recovery instead of trying to rejoin a
  lobby that no longer exists.

The tournament scoring change and the server half of the recovery fix are
already live for everyone. The client is based on 3.0.4.
The 5v5 (1.0.31), 1v1 (1.0.5) and CTF (1.0.4) packs are unchanged.

Validation:

- server tests: a tournament total below 0 is raised to 0 once, later losses
  stop at 0, totals above 0 are not rescored, and receipt order cannot change
  the result; the recovery route is reachable by a signed-in hub
- client tests: Reconnect is withdrawn and recovery is used once the host's
  session is stale
- the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
