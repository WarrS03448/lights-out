# Lights Out for Linux 3.0.7 (beta)

This is a beta of the native Linux version of Lights Out, for 64-bit x86 PCs.
It works with the same service, queue and ranks as the Windows app.

- Click "Download for Linux (beta)" on lightsoutranked.com, extract the ZIP and
  open "Install and Open Lights Out". It installs into your user account
  (under ~/.local/share and ~/.local/state); no terminal or administrator
  password is needed.
- It needs Bodycam installed through the regular Steam app and run with Proton.
  Sign in with Steam; Lights Out accounts are not available on Linux yet.
- Close Bodycam yourself after a match.
- The app updates itself from its update strip. Opening a newer download also
  updates it. Uninstall it from Settings.
- Beta: tested on Arch Linux, Ubuntu 22.04 and 24.04, Debian 12, Fedora 44 and
  openSUSE Leap 16. Known differences from the Windows app: the screens are
  drawn flat, without the Windows app's raised shading; Russian and Chinese
  text uses a fallback font; emoji show as "?"; the report form uses a
  different font; Turkish, Azerbaijani and Lithuanian capital letters follow
  English casing; the update strip's buttons are square; the uninstall list of
  removed files uses the normal font instead of a fixed-width one.
