# Lights Out 3.0.4

This release updates the cross-region explanation on the Competitive screen.

- Cross-region matchmaking no longer has a 120 ms ping limit. If every
  player in a match has ticked **Cross-region**, the match can form at any
  measured ping, so players in smaller regions find games more often.
- Matches in your own region still come first, and a match where everyone
  is within 120 ms of the host is still preferred over one that is not.
  Players who have not ticked **Cross-region** keep the 120 ms limit.
- The Cross-region tooltip said "The 120 ms limit always applies". It now
  describes the new rule, in all seven languages.

The matchmaking change is on the server and is already live for everyone.
This release only updates the tooltip text. The client is based on 3.0.3.
The 5v5 (1.0.31), 1v1 (1.0.5) and CTF (1.0.4) packs are unchanged.

Validation:

- server tests: a cross-region match forms at 250 ms, a same-region match
  without the opt-in is still refused above 120 ms, and a host or roster
  within 120 ms still beats one outside it
- the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
