# Lights Out 3.0.3

This release lets you install Bodybomb 1v1 again after the latest Bodycam
update.

- Bodycam's update of 25 September changed the Bomb House map, and
  installing Bodybomb 1v1 on the updated game stopped with "The installed
  game version does not match the reviewed 1v1 maps. No map was
  installed." Lights Out builds the 1v1 maps from your own copy of the game
  and only uses map versions it has checked, and the update had changed
  Bomb House. The only change was 4 bytes in the map's weather settings.
  The bombsites and the rest of the level were unchanged, so the updated
  Bomb House is now accepted. The version from before the update is still
  accepted too, so players who have not updated Bodycam yet can install as
  before.
- If a future Bodycam update changes one of these maps before Lights Out
  has checked it, the message now names the map and says that a Lights Out
  update is needed. The problem is not on your PC.
- Players whose 1v1 install was made before the update were not affected
  and do not need to reinstall.

The client is based on 3.0.2. Server code is unchanged. The 5v5 (1.0.30),
1v1 (1.0.4) and CTF (1.0.4) packs are unchanged.

Validation:

- on the updated game, installing 5v5, 1v1 and CTF together failed with the
  reported message on 3.0.2 and succeeds now, and every map check passes
- the new Bomb House 1v1 map differs from one installed before the update
  only in those 4 weather bytes, so the retained bombsite is still the
  downstairs one
- tests that accept both Bomb House versions and reject any other version,
  and the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
