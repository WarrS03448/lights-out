# Lights Out 3.0.1

This release keeps the language list in Settings open while you choose from
it, and fixes the wording of the language prompt.

- The language list in Settings no longer closes by itself about a second
  after you open it. The client redraws its screens several times a second,
  and every redraw closed the open list. The list now stays open until you
  pick a language or click away, and the rest of the screen keeps updating
  behind it. Every other list in the client was checked the same way and
  already stayed open: the ranked region, the leaderboard filters and
  sorting, the Messages friend picker, the tournament issue type and the
  Friends actions menu.
- The language prompt shown on first launch now reads "Choose the language
  for Lights Out." instead of "for the Lights Out.", a leftover from the
  rename. German, Spanish and French had the same slip and are fixed too.

The client is based on 3.0.0. Server code is unchanged. The 5v5 (1.0.30),
1v1 (1.0.4) and CTF (1.0.4) packs are unchanged.

Validation:

- a browser test that opens the Settings language list and sends changed
  snapshots: it fails on 3.0.0 and passes now
- the same check on every other list in the client, each staying open
  through eight changed snapshots
- the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
