# Lights Out 2.8.6

This release fixes client display problems found by checking every screen
against the data the service actually sends.

- Profile's 5v5 and 1v1 rank badges now draw at their intended size. They had
  stretched to fill their cards.
- The match result screen lists the players from that match again, with a
  Report button beside everyone except you. The list had never been drawn. A
  report opened without a name now shows the player's name, not a Steam ID.
- Match history shows the score of every settled match. Server-recorded
  matches had all read "no score". The fallback window used when the web view
  cannot start had the same problem and is fixed too.
- Profile's recent matches show the RR each match moved, or Placement for a
  placement match. Ordinary matches had all read "Unavailable".

The client is based on 2.8.5, preserving native update-signature verification
and stock multiplayer enum compatibility. Server code is unchanged. The 5v5
(1.0.30), 1v1 (1.0.4) and CTF (1.0.4) packs are unchanged.

Validation includes client regression tests for each fix, each failing on
2.8.5, browser checks of every changed web screen against 2.8.5 using
server-shaped data, and signature and frozen self-check verification.

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
