# Lights Out 2.8.7

This release makes counts read correctly in every language, and fixes two
problems in the fallback window that its UI tests found once they were run for
real.

- Counts now agree with their noun in all seven languages. The placement line
  read "1 more placement matches required for rank calibration" and now reads
  "1 more placement match". Russian now uses the right form for every number,
  including the registration counts in the header. The rank guide, the result
  screen and the post-match card are fixed too, and so is the fallback window.
- In the fallback window used when the web view cannot start, an open profile
  now updates when your RR or placement count changes. Before, it kept the
  numbers it was opened with until you reopened it.
- In the same window, a queue ban now counts down on Match History and the
  profile. Before, it stayed at the time it was drawn with.

The client is based on 2.8.6. Server code is unchanged. The 5v5 (1.0.30),
1v1 (1.0.4) and CTF (1.0.4) packs are unchanged.

Validation:

- regression tests for each fix, each failing on 2.8.6
- the fallback window's UI tests run against Windows Tk: all eight pass, and
  four had been failing without anyone noticing
- a check that the web UI and the client choose the same form for every count
  up to 1000 in all seven languages
- browser checks of the changed web screens in English, German and Russian
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
