# Lights Out 3.0.7

This release fixes a ranked match where the host's game never opens after the
map bans.

- The host's Bodycam now opens after the map bans even if Lights Out hits an
  error while it prepares the match. Before a ranked match, the host's Lights
  Out builds a small lobby file for the chosen map. If anything went wrong
  while building it, Lights Out stopped handling the start of the match
  without saying why: the game never opened, the countdown never started and
  the other players waited until the match was cancelled. Lights Out now
  records the error, removes the half-built file, tells the host it could not
  prepare the launch and keeps the match window open.
- When Lights Out does not open the game at the start of a match, it now
  reports the reason (for example, the game was already running, the map is
  missing from the installed gamemode, or the lobby file could not be built).
  This lets us see and fix these cases instead of guessing.

The client is based on 3.0.6.
The 5v5 (1.0.31), 1v1 (1.0.5) and CTF (1.0.4) packs are unchanged.

Validation:

- client tests: an error while building the host's lobby file is logged, the
  file is removed, the host sees the error and the match window stays open;
  each reason a launch is skipped is reported once per match, and a normal
  launch reports nothing new
- the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
