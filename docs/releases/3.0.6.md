# Lights Out 3.0.6

This release fixes a game launch that hangs on "waiting for connection" and
then goes black after a ranked match.

- Bodycam no longer tries to rejoin a finished match when you start it
  normally. Before a ranked match, Lights Out adds a small lobby file to the
  game. Quitting Lights Out from the result screen, an update restart or a
  reboot could leave that file behind, and every later launch, including
  from Steam, then waited for a match that was over and showed a black
  screen instead of the shooting range. Lights Out now removes a leftover
  file when it starts while the game is closed, and removes it after a
  match once the game has closed, even if Lights Out itself was closed
  first.

If your game is stuck like this and you cannot update yet, close Bodycam and
delete `Bodycam\Content\Paks\~mods\CommunityLobby_P.pak`. Do not delete
`CommunityGamemodes_P.pak`.

The client is based on 3.0.5.
The 5v5 (1.0.31), 1v1 (1.0.5) and CTF (1.0.4) packs are unchanged.

Validation:

- client tests: the leftover file is removed at startup only while the game
  is closed; after a completed match, the file is removed only if it belongs
  to that match and no game is running; it is kept when the game stops
  mid-match, so Reconnect can still use it
- the full client test suite
- signature and frozen self-check verification

Lights Out is an unofficial community project, not affiliated with or endorsed
by Reissad Studio. Its purpose is community gamemodes, not cheating, and its
downloads are not designed to provide cheats.
